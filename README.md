# Colourplus Website Prototype

A high-fidelity Next.js prototype for Colourplus Polyurethanes Pvt. Ltd.

## Run locally

1. Open this folder in VS Code.
2. Open a terminal in the project folder.
3. Run:

```bash
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
npm install
npm run dev
```

4. Open `http://localhost:3000`

## Prototype scope

The first build focuses on:
- Premium industrial + architectural visual language
- Homepage
- Solution Finder interaction
- Solutions
- Industries
- Projects
- Colourplus Intelligence
- Colour Studio teaser
- Responsive navigation

The AI, Floor Passport, Factory Health, client portal and channel-partner functions are presented as roadmap/prototype concepts, not as confirmed live systems.
